# Login & Signup System

A command-line Login and Signup System built using Python.

This project allows users to create an account, log in, reset their password, and access a simple user dashboard.

## Features

- User Signup
- Username validation
- Password validation
- Confirm password
- Duplicate username checking
- User Login
- Maximum 3 login attempts
- Remaining attempts display
- Access blocked after too many incorrect attempts
- Forgot/Reset password
- User Dashboard
- View profile
- Change password
- Logout system
- Invalid menu choice handling

## Password Requirements

The password must contain:

- 6 to 8 characters
- At least 1 uppercase letter
- At least 1 number

## Username Requirements

The username must contain:

- 8 to 12 characters
- At least 1 uppercase letter
- At least 1 number

## Main Menu

The program provides the following options:

1. Signup
2. Login
3. Forget Password
4. Exit

## User Dashboard

After successfully logging in, the user can:

1. View Profile
2. Change Password
3. Logout
